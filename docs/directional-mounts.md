# Направленная тяга и оружейные крепления

## Исправление круговой стрельбы Fixed

Причина: CanAim проверял только сектор крепления; собственный сектор Fixed
отсутствовал. Демонстрационные 360° второго крепления разрешали курсовой
пушке выстрелы сбоку и сзади. Ошибка воспроизведена MCP до исправления.
Теперь Fixed проверяет пересечение своего полного сектора 60° и сектора
крепления, от фактического firePoint. Universal не расширяет сектор оружия.

## Три независимых типа

Laser/Plasma/Railgun — тип оружия. Fixed/Turret — тип установки.
FixedOnly/TurretOnly/Universal — совместимость крепления, не его сектор.
Fixed допускается в FixedOnly/Universal, Turret в TurretOnly/Universal.
Проверки выполняются при drop, быстром оснащении, обмене в обе стороны,
загрузке комплекта, применении активного сохранения и смене корабля.

## Все корабли библиотеки

ShipDefinition содержит hardpoints: стабильный id, slotIndex, localAxis,
compatibility, sector. Позиция берётся из существующего firePoints[slotIndex];
ссылки сохранены, ось не вращается при наведении турели.

| Корабль | Слот | Совместимость | Ось | Полный сектор |
|---|---:|---|---|---:|
| Cobra MK3 | 1 | FixedOnly | нос | 60° |
| Cobra MK3 | 2 | FixedOnly | нос | 60° |
| Cobra MK3 | 3 | TurretOnly | нос | 360° |
| Cobra MK3 | 4 | Universal | нос | 180° |
| Sidewinder | 1, 2 | FixedOnly | нос | 60° |

Других ShipDefinition в Assets нет. Для неопределённых старых креплений
без паспорта используется консервативный FixedOnly, не Universal.
ID имеют вид shipId:weapon:zeroBasedIndex. Перезарядки хранятся по ID;
обновление UI и списка оборудования не сбрасывает готовность.

## Сохранения и миграция

Активный JSON: formatVersion=3, weaponSlots сохраняет позиции и пустые
элементы. JsonUtility-пустышки нормализуются в null без удаления индекса.
Старые уже уплотнённые списки читаются по сохранённому порядку. Несовместимые
или выходящие за вместимость предметы переносятся в inventory с сообщением
в журнале подготовки. Повторная миграция не добавляет копий.
Файлы и PlayerPrefs не сбрасываются.

Комплекты сохраняют пустые ID как пустые позиции, formatVersion=3; прежний
ключ TheGame.Loadout.v2 сохранён для чтения старых комплектов. Загрузка
сначала собирает отдельный результат и проверяет предметы, вместимость и
совместимость. При ошибке текущее оснащение не меняется; ремонт комплекта
по правилам миграции активного сохранения не выполняется.

Сохранение игрока при проверке: w3 и w2 остались в слотах 1/2; Fixed w1
из нового TurretOnly слота 3 перенесён в инвентарь. Демотурель одна.

## Проверки этого исправления

28/28 EditMode; 14/14 PlayMode — фактически выполнены после изменений.
PlayMode включает реальный выстрел смешанного оснащения, отсутствие энергии
и КД до наведения, пустой промежуточный слот, собственный сектор Fixed на
360°, сужение креплением, вращение корпуса, границы и ограничение турели.
MCP: Fixed до исправления side/rear=true; после false, front=true.
Реальная временная смешанная конфигурация: стреляло только крепление 3,
наведение -90° сбоку и 180° сзади. Сохранённое оснащение не заменялось.
Фитинг просмотрен 1280×720 и 1920×1080. Полная ручная матрица drag/drop,
обменов и всех комплектов физической мышью не выполнена.

Ориентация переключается в правой панели: «По курсу» и «На цель приказа».
Выбранная оружейная цель не меняет ориентацию. Точки и Orbit по умолчанию
следуют курсу; Engage/KeepDistance смотрят на цель. Flank переключает этап
при расстоянии менее 0.65 и выходит из атаки далее 1.4. Stop тормозит первым.

baseAcceleration — историческое имя поля маршевого усилия, не ускорения.
Новые baseReverseThrust/baseLateralThrust задают базовую силу; нулевые старые
данные означают 50%/35%. Оборудование и форсаж масштабируют все оси.
Нормированный эллиптический бюджет исключает бесплатную диагональную тягу.
Масса влияет через AddForce; тормозной расчёт использует текущую ориентацию.

Fixed не вращается; Turret наводится с конечной скоростью. Оба ограничены
сектором крепления, дальностью от firePoint, захватом и реактором. Старые
данные остаются Fixed, старый сектор сохраняется. Тип Laser/Plasma/Railgun
не определяет тип установки. Частичный сектор не пересекает запрещённую дугу.

Демо: w_laser_turret_demo, 11 урона вместо 15, 90 °/с, допуск 3°.
Предмет доступен после открытия фитинга без сброса сохранений. В CombatSandbox
крепление 3 допускает 360°, крепление 4 — 180°. Для боковой стрельбы ставьте
турель в третье или четвёртое крепление. Это стартовый баланс.

Ограничения: простое обозначение ствола; его обновление без боевого захвата
требует дальнейшей визуальной доработки. Выбранный сектор показывается при
наведении на слот фитинга, только один одновременно; для Fixed используется
пересечение двух секторов. Нет глобального поиска пути (не относится к оружию).
